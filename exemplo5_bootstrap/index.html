Como jogar
  • Tabuleiro 10×10 com 5 navios: Porta-aviões (5), Encouraçado (4), Cruzador (3), Submarino (3), Contratorpedeiro (2).
  • Posicionamento: clique na sua frota para posicionar cada navio. Pressione R ou o botão Girar para alternar horizontal/vertical. "Aleatório" posiciona tudo automaticamente.
  • Batalha: clique na água inimiga para disparar. Cada jogador dá um tiro por vez. Acerto = vermelho, água = branco, navio afundado = borda dourada.
  • Modo 2 jogadores: revezam no mesmo teclado. Entre as fases de posicionamento aparece um aviso para passar o dispositivo.
  • Dificuldade: Fácil = tiros aleatórios. Médio = após acertar, mira nas casas adjacentes. Difícil = caça com direção inteligente.
  • Vitória: afunde todos os navios inimigos!
