Como jogar

O objetivo é encontrar todos os pares de imagens.

  1. Clique em uma carta para revelá-la.
  2. Escolha uma segunda carta e tente encontrar a imagem igual.
  3. Se as cartas forem diferentes, elas voltam a esconder a imagem.
  4. O jogo termina quando os oito pares forem encontrados.
